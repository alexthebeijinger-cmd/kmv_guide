Закрой открытый вопрос: $ARGUMENTS

1. Найди этот вопрос в `knowledge/OPEN-QUESTIONS.md` и в соответствующей карточке `knowledge/<category>/<id>.md` (секция «Что осталось уточнить»).
2. В обоих местах — зачеркни пункт (`~~текст~~`) и добавь пометку «закрыто DATE (Alex): <ответ/факт>». Не удаляй пункт молча — только зачёркивание, кроме случая полевого чек-листа для внешней передачи (там правило другое, см. CLAUDE.md).
3. Если закрытие вопроса освобождает карточку от всех блокеров — рассмотри смену `status: draft` → `status: ready`.
4. Если новый факт противоречит уже написанному в карточке — исправь текст, а не просто допиши в конец.
5. Закоммить и запушь: `git add ... && git commit -m "..." && git push origin main`.
6. Ответь коротко, нумерованными пунктами.
