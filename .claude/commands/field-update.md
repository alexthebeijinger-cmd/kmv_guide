Alex прислал с места фото и/или текстовую правку по объекту: $ARGUMENTS

Выполни по конвенциям из CLAUDE.md:

1. Определи, к какой карточке в `knowledge/` относится присланное (по названию/координатам/контексту разговора). Если карточки нет — создай новую по стандартному формату (см. CLAUDE.md, секция «Рабочие конвенции»).
2. Если это фото — сохрани его в `knowledge/<category>/photos/<описательное-имя>.jpeg`, добавь в `photos:` фронтматтера и сошлись на него в тексте с атрибуцией «(Alex, DATE)».
3. Если объект уже был на Яндекс.Картах/2ГИС с фото/рейтингом — сначала проверь эти источники сам, не проси Alex переснимать то, что там уже есть.
4. Обнови соответствующие пункты в «Что осталось уточнить»: закрой зачёркиванием с пометкой «закрыто DATE (Alex): ...», не удаляй молча.
5. Если это резолвит вопрос из `knowledge/OPEN-QUESTIONS.md` — зачеркни и там тоже.
6. Если правка меняет факт, уже написанный в другой карточке (перекрёстная ссылка, дубль объекта) — проверь и поправь и там.
7. Закоммить и запушь: `git add ... && git commit -m "..." && git push origin main`.
8. Ответь коротко, нумерованными пунктами, на русском — что изменено.
