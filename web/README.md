# Веб-часть «КМВ Гид» — чат-гид (прототип интерфейса)

## Как посмотреть

Из корня репозитория:

```
pip install -r scripts/requirements.txt
uvicorn server:app --reload --port 8812
```

и открыть <http://127.0.0.1:8812/>. Так запускаются и интерфейс, и RAG-бэкенд.
Файл `.env` в корне обязателен: в нём `QDRANT_URL`, `QDRANT_API_KEY`,
`DEEPSEEK_API_KEY`. Шаблон без ключей — `.env.example`. Просто открыть `index.html`
двойным кликом нельзя — браузер не даст прочитать `data/places.json` с диска, а чат
не найдёт API.

## Как добавить место

1. Создать файл в `knowledge/<категория>/<имя>.md` по схеме из `knowledge/SCHEMA.md`.
2. **Адрес обязателен.** Без него место не попадёт на сайт — сборка скажет об этом списком.
3. Фотографии положить рядом, в подпапку `photos/`, и перечислить в поле `photos`.
4. Для еды указать `food_types` — иначе место не попадёт в подбор по типу.
5. Двойной клик по **«Обновить данные сайта.command»** в корне репозитория.
6. Обновить страницу в браузере.

Сборка печатает отчёт: сколько мест собрано, что выпало из-за отсутствия адреса, у чего не заполнены часы. Отчёт — это и есть список дел по контенту.

## Первый экран

Единственный объект первого экрана — **широкое поле свободного вопроса** с двумя латунными кранами: голосовой ввод и отправка. Плиток, семплов и образцов вопросов нет намеренно (решение зафиксировано в `CLAUDE.md`): любой набор плиток заведомо уже реальных потребностей человека и превращает чат-гид обратно в справочник с меню.

Поле — один элемент в двух состояниях, а не два разных поля: на первом экране это большая эмалевая табличка на крючках под стойкой, после первого вопроса та же разметка садится узкой строкой по нижнему краю. Переключает состояние класс `is-start` на `<body>`.

Уточняющий шаг («что именно ищем», «сколько у вас времени», «откуда считать») живёт внутри разговора, а не на первом экране, и после ответа гаснет: выбранный вариант остаётся тёмным, остальные становятся неактивными.

**Голосовой ввод** работает на браузерном распознавании (Web Speech API), без бэкенда и бесплатно. Это ввод вопроса, а не платный голосовой переводчик из пропуска за 3900 ₽ — не путать их ни в интерфейсе, ни в биллинге. Где браузер распознавание не умеет, кнопки просто нет.

## Что здесь настоящее, а что нет

**Настоящее:** все места, адреса, часы, описания и фотографии — из `knowledge/`. Расстояния и время ходьбы считаются от вашего фактического положения. Состояние «открыто / закроется через N минут / сегодня выходной» вычисляется из часов работы и текущего времени. Порядок дня не ставит точку, до закрытия которой остаётся меньше получаса, и не назначает прогулки на ночь — вместо этого честно говорит, что день кончился.

**Прототип (о чём говорит метка в шапке):**

- **Гид отвечает по локальным правилам, а не через RAG.** Qdrant и роутинг DeepSeek→Gemini→Claude не подключены. Подключение меняет функцию `ask()` в `app.js`, а не вёрстку.
- **Координаты приблизительные** — лежат в `data/coords.prototype.json`. По `knowledge/SCHEMA.md` настоящие координаты должны приходить из геокодирования адреса. Пока они прикидочные, расстояния показываются со знаком «≈».
- **Ответ партнёра на заявку не приходит.** На карточке заявки есть служебный переключатель состояний с подписью «Прототип» — он существует, чтобы посмотреть, как выглядят «подтверждено», «отказ» и «партнёр молчит». В рабочей версии этого блока нет.
- **Расписания транспорта и подбор санатория по диагнозу** не подключены — гид честно говорит об этом вместо выдуманного ответа.
- **Китайская версия** переводит интерфейс и все реплики гида, но не названия, адреса и описания мест: машинного перевода курированного контента здесь нет намеренно.

## Файлы

| Файл | Что это |
|---|---|
| `index.html` | Каркас и контракт направления в комментарии сверху |
| `app.css` | Весь стиль мира «Бювет». Токены и правила — в `DESIGN.md` в корне |
| `app.js` | Строки обоих языков, логика гида: разбор часов, расстояния, порядок дня, ветка еды, заявка, страница места, голосовой ввод |
| `data/places.json` | Собирается скриптом, руками не править |
| `data/coords.prototype.json` | Временные координаты, править можно |
| `fonts/` | Commissioner и Golos Text локально, только кириллица и латиница |
