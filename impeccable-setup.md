# Настройка Impeccable для КМВ Гид (kmv_guide) — сводка

Рабочая папка проекта: `~/Desktop/КМВ Гид/kmv_guide`
(название «КМВ Гид» — рабочее, для списка проектов; финальное имя/айдентика ещё не определены)

## Контекст
- Интерактивный туристический гид по Кавказским Минеральным Водам (вода/бальнеология, история, рестораны, горы, маршруты, музеи)
- MVP: только Пятигорск, ~30-50 точек, 10-15 маршрутов, Telegram + web на одном бэкенде, без карт на первом этапе
- Построен на стеке [[balneo-bot]] (RAG), но отдельная Qdrant-коллекция — не смешивать медицинский и туристический контент
- Каналы: Telegram-бот + веб-интерфейс; рассматривается WeChat для китайских туристов; Max-мессенджер сознательно не используется
- Продвижение: QR-код на вокзале и в аэропорту при въезде в регион
- Оплата: без предоплаты через бота, оплата на месте после визита/трапезы
- Планируется аудио-слой: озвучка маршрутов + голосовой диалог с гидом

## Установка Impeccable
```
cd ~/Desktop/"КМВ Гид"/kmv_guide
npx impeccable install
```
При установке выбрано:
- Harness: **Detected only** (claude, codex)
- Install location: **Project** (не Global) — каждый визуальный проект получает установку отдельно, со своим `PRODUCT.md`/`DESIGN.md`

Запуск инициализации — из корня проекта:
```
cd ~/Desktop/"КМВ Гид"/kmv_guide && claude
```
затем внутри Claude Code:
```
/impeccable init
```

## Решения по `/impeccable init`
| Параметр | Выбор | Обоснование |
|---|---|---|
| **Формат сайта** | Чат + витрина контента | Нужны SEO-страницы мест/маршрутов/ресторанов с фото и картой + витрина партнёров для бронирования. Личный кабинет не нужен на этом этапе — история заявок через Telegram |
| **Языки на старте MVP** | Русский + китайский | Китайский — под уже запланированный канал WeChat/китайских туристов. Английский не включён: КМВ — курортный регион с преимущественно российским и китайским потоком, не международный туристический хаб; добавление языка — это ещё и постоянная поддержка контента, не только перевод интерфейса |
| **Бренд** | Имя рабочее, айдентики нет | «КМВ Гид» — временное название для списка проектов, не финальный бренд. Айдентика balneo_bot сознательно не наследуется — разные аудитории (научный институт курортологии vs турпродукт для широкой аудитории) |
| **Основной сценарий** | Мобайл-фёрст без возрастных требований | Аудитория широкая (разные возраста, семьи, молодёжь), не только санаторные туристы 55+ — поэтому без принудительно увеличенного кегля/контраста сверх стандарта WCAG AA. Мобайл-фёрст всё равно обязателен: сценарий использования — QR-код на вокзале/в аэропорту, "телефон на улице, одной рукой" |
