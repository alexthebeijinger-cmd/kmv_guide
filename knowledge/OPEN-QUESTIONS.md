# Открытые вопросы по базе знаний

Единый список всего, что нужно добрать по объектам: позвонить, съездить, сверить.

**Правило работы (зафиксировано Alex, 28.07.2026):** сейчас набираем максимум объектов вширь — основу. Мелкие детали (телефоны, цены, точные часы) отрабатываем **потом, одним заходом**, а не по каждому объекту сразу. Не тормозить сбор точек ради добора одного телефона.

Этот файл — накопитель. При создании новой карточки её открытые вопросы дублируются сюда. Закрытые вопросы вычёркиваются (`~~зачёркиванием~~`), а не удаляются — чтобы было видно, что уже проверяли.

Обновлено: 01.08.2026 (закрыты висящие решения по монетизации — дневной лимит и реклама, см. §0-квинто; далее — перезагрузка в Qdrant)

## Бэклог продукта (зафиксировано Alex, 31.07.2026, по итогам правок «умного товарища»)

Не блокирует текущий сбор карточек, но нужно учесть на этапе сборки бота:

1. **Аналитика.** Собирать: что спросил пользователь, что ему показали, что он выбрал, на каких запросах гид не понял намерение. Нужно решить, куда пишутся события (отдельная БД/таблица) и в какой момент подключать — не на этапе сбора базы знаний.
2. **Главная метрика MVP.** Не «сколько карточек в базе», а реальные действия пользователя: задал вопрос → увидел варианты → выбрал место → построил маршрут → вернулся снова. Держать в уме при проектировании интерфейса и бронирования — метрика про действие, не про просмотр.

### 65. Ручной заход через Яндекс.Карты + 2ГИС — геокодирование закрыто (30.07.2026)

По прямому указанию Alex («бери координаты из Яндекса и 2ГИС») добраны вручную все объекты, не поддавшиеся автоматике: опечатки/ТЦ-адреса (15 карточек — Nominatim после ручной чистки адреса), дальние экскурсии (4 из 5 — Архыз, Домбай, Джилы-Су, Черекское ущелье; для «Голубых озёр» использован альтернативный запрос), и весь корпус парков/гор/скверов (29 карточек) — через прямой поиск по названию на Яндекс.Картах (координата берётся из `ll=` в URL страницы организации) либо через 2ГИС (координата извлекается из `geoPosition` внутри ссылки на карточку места в выдаче поиска, доступна без захода на саму страницу).

**Метод для 2ГИС (новый, быстрее Яндекса для этого типа объектов):** искать объект на `2gis.ru/pyatigorsk/search/...`, найти нужную ссылку на карточку места в результатах, координаты `lon`/`lat` закодированы в base64 внутри параметра `stat` её `href` — не требует захода на страницу самого объекта.

**Результат:** из 189 карточек — **172 с координатами (91%)**, включая одну случайно пропущенную в предыдущем заходе (`history/eolova-arfa-besedka.md`, добрана отдельно). Осталось намеренно без координат **16 файлов** — справочные/сетевые материалы без единой физической точки (см. список в §64), плюс `SCHEMA.md` (не карточка) — координаты им не нужны в принципе.
