# Инфраструктура для иностранцев: обмен валюты, SIM-карты, банкоматы

**Категория:** справочная информация, пункт 19 чек-листа («Инфраструктура для иностранцев»). Отдельные карточки на банки/салоны не заводятся — это инфраструктурный справочник, а не туристические точки притяжения.
**Статус:** черновик, источник — Яндекс.Карты (мониторинг Alex через Claude, 30.07.2026).

## Обмен валюты

Топ банков по рейтингу с функцией обмена валюты (фильтр Яндекса «обмен валюты»):

- **Россельхозбанк** — просп. Калинина, 38А, стр. 2 — Яндекс 5,0 (539 оценок). **Акция: бесплатная карта UnionPay для покупок за границей** — прямо релевантно для китайского трека проекта (UnionPay — основная платёжная система для гостей из Китая).
- **СберБанк** — просп. 40 лет Октября, 56В — Яндекс 4,7 (836 оценок), крупнейшая сеть отделений в городе.
- **Банк ПСБ** — просп. Калинина, 92 — Яндекс 4,3 (253 оценки), акция «Обмен валюты».

## SIM-карты

Салоны сотовой связи представлены по всему городу (МТС, Билайн, МегаФон, Т2) — плотная сеть, отдельно не картировали каждый. Пример точки МТС рядом с уже задокументированным ориентиром: просп. Кирова, 36 (Яндекс 4,0/201); ещё одна — на ул. 295-й Стрелковой Дивизии, 1 (тот же ТЦ «Лермонтовский»/«Магнит», что уже встречался при поиске ремонта телефонов, см. §41).

## Банкоматы

Отдельно не картировали — банкоматы есть при каждом отделении банка и в торговых центрах. Практический момент для гида: **не все банкоматы обслуживают карты UnionPay/иностранные карты** — это стоит уточнять на месте у конкретного банка, а не утверждать общим правилом.

## Что осталось уточнить

1. Какие именно банки/банкоматы в Пятигорске гарантированно принимают UnionPay — ключевой вопрос для китайского трека, требует звонков или визита в отделения.
2. Комиссия и курс обмена валюты у топ-банков — не сравнивали.
3. Есть ли в городе специализированные пункты обмена (не банковские) — не искали отдельно.
4. Визит Alex на месте — фото.
