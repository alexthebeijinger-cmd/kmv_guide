# Экскурсия в Приэльбрусье (гора Эльбрус)

**Категория:** экскурсия за пределы КМВ, кабинетный материал (без выезда — по данным туроператоров).
**Статус:** черновик, источник — интернет (сайты турагентств), 30.07.2026.

## Кратко

Маршрут: Пятигорск → гора Чегет → гора Эльбрус (поляна Азау, три уровня канатных дорог: 3000 м / 3500 м / 3900 м) → поляна Нарзанов → Пятигорск. Полный день, отправление рано утром.

## Практическая информация

| Параметр | Значение |
|---|---|
| Длительность | ~14 часов (06:00–20:00) |
| Дни | вторник, четверг, суббота, воскресенье |
| Базовая цена | от 3000 ₽ |
| Доп. расходы | подъём на Чегет 1100 ₽, канатки Эльбруса 3200 ₽, эко-сбор 200 ₽ |
| Питание | завтрак и национальный обед — по желанию, за доп. плату |
| Противопоказания | подъём по канатным дорогам не рекомендуется людям с сердечно-сосудистыми заболеваниями |

## Для контента гида

- Самая известная и «статусная» экскурсия за пределы КМВ — гора Эльбрус узнаваема даже у туристов, которые вообще не планировали ехать в горы. Хорошо предлагать как «топовый» вариант для активных туристов с 1–2 свободными днями.
- Погодозависимый объект — верхние уровни канатки может закрыть по погоде; фирмы явно снимают с себя ответственность за погодные условия. Стоит предупреждать туриста заранее.
- Полный день — не подходит для гостя с жёстким лечебным графиком санатория; логичнее предлагать в начале/конце заезда.

## Что осталось уточнить

1. Сезонность — не зафиксирована явно источником, требует уточнения (вероятно, круглогодично, но с разными условиями).
2. Актуальные цены на дату публикации — сверить перед использованием (цены на экскурсии быстро меняются).
3. Конкретный туроператор-партнёр — не выбран, материал кабинетный, без привязки к конкретной фирме.
