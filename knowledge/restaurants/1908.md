# Кофейня «1908»

**Категория:** кофейня
**Адрес:** г. Пятигорск, ул. Орджоникидзе, 2
**Статус:** партнёр пилота (зафиксировано с Alex)

## Описание

Уютная кофейня с качественным кофе и хорошим выбором чаёв, свежие десерты. Есть Wi-Fi — подходит и для короткого визита, и для того, чтобы посидеть поработать/отдохнуть.

## Заметки с места (от Alex)

Уютно, вкусные и свежие десерты, качественный кофе, отличные чаи. Есть вайфай.

Фото интерьера: `photos/1908-interior.jpeg`

## Для контента гида

- Годится как рекомендация «где выпить кофе и передохнуть» в маршрутах по центру Пятигорска.
- Кандидат на короткую заметку в китайской версии (тихое место с Wi-Fi может быть релевантно туристам, которым нужно выйти на связь/поработать).

## Открыто

- Точный чек, часы работы, наличие точек с розетками — уточнить при личном визите или через 2ГИС/Яндекс.Карты.
- Контакт для переговоров о партнёрстве (Telegram/телефон) — не зафиксирован.
