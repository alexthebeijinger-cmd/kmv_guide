# Кафе «Провалъ»

**Категория:** кафе/ресторан
**Адрес:** г. Пятигорск, бульвар Гагарина, 30
**Часы работы:** 10:00–24:00 (по вывеске на месте)
**Статус:** кандидат в контент (партнёрство не обсуждалось — статус партнёра не зафиксирован, см. `CLAUDE.md`)

## Описание

Уютное кафе в стиле прованс/кантри: дерево, плетёные корзины, картины в рамах, мягкий свет. Есть отдельная летняя веранда с садом — живые растения по решётке, гирлянды-огоньки, декоративная коллекция скворечников/домиков как элемент оформления. Судя по фото — подходит и для спокойного семейного визита, и для вечерних посиделок на веранде.
