# «Хачапури и…»

**Категория:** уличная еда / фастфуд (грузинская кухня)
**Адрес:** г. Пятигорск, бульвар Гагарина, 31
**Статус:** кандидат в контент (партнёрство не обсуждалось — статус партнёра не зафиксирован, см. `CLAUDE.md`)

## Описание

Киоск формата «окно на улицу» с грузинской уличной едой: хачапури (в т.ч. по-аджарски), хинкали, хычины, шаурма, напитки. По фото — оперативная точка навынос/на месте у окна, есть меню с фото и ценами прямо на фасаде.

- Хачапури по-аджарски
- Хинкали
- Хычины
- Шаурма
- Осетинские пироги
- Напитки (чай, лимонад, кофе)
