# Лермонтовские ванны

**Категория:** историческое здание, пункт «максимум достопримечательностей» (запрос Alex, 30.07.2026).
**Статус:** черновик, источник — Яндекс.Карты (мониторинг Alex через Claude, 30.07.2026).

## Кратко

Яндекс.Карты: **5,0 (335 оценок)**. Историческое здание в центре Пятигорска, рядом с парком «Цветник» (`parks/park-tsvetnik.md`, уже в базе) и Лермонтовской галереей. **Сейчас в здании располагается отель** — не действующие лечебные ванны, а архитектурная/историческая достопримечательность с современной функцией.

## Для контента гида

- Соседствует с «Ермоловскими ваннами» (`history/ermolovskie-vanny.md`, тоже создана этим заходом) по тому же адресу — два исторических здания рядом, хорошая связка для прогулки по парку «Цветник».

## Что осталось уточнить

1. Название отеля, который сейчас занимает здание — не зафиксировано.
2. Историческая связь с именем Лермонтова — почему называются именно так.
3. Визит Alex на месте — фото.
4. Точные координаты — геокодирование при загрузке в базу.
