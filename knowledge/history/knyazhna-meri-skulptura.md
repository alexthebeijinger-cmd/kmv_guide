# Скульптура «Княжна Мери»

**Категория:** жанровая скульптура, часть литературного маршрута по мотивам «Героя нашего времени» Лермонтова, пункт «максимум достопримечательностей» (запрос Alex, 30.07.2026).
**Статус:** черновик, источник — Яндекс.Карты (мониторинг Alex через Claude, 30.07.2026).

## Кратко

Яндекс.Карты: **4,9 (196 оценок)**. Скульптура изображает княжну Мери, будто гуляющую по тенистой аллее парка — героиню повести «Княжна Мери» из романа М.Ю. Лермонтова «Герой нашего времени». Расположена в Емануелевском парке (`parks/emanuelevsky-park.md`, уже в базе).

## Для контента гида

- Часть литературного маршрута вместе с Максимом Максимычем (`history/maksim-maksimych-skulptura.md`) и Бэлой (`history/bela-skulptura.md`), все в одном парке — компактный «квест по героям романа» одним ответом.
