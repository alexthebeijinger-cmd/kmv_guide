# «Рельс» (жанровая скульптура)

**Категория:** малая жанровая скульптура, пункт «максимум достопримечательностей» (запрос Alex, 30.07.2026).
**Статус:** черновик, источник — Яндекс.Карты (мониторинг Alex через Claude, 30.07.2026).

## Кратко

Яндекс.Карты: **5,0 (59 оценок)**. Небольшая жанровая скульптура, отзыв: «Классное место, памятник сохранился в идеале». Точный адрес карточкой Яндекса не указан — только «Пятигорск».

## Для контента гида

- Малый арт-объект, хорошо подходит для «квеста по мелким достопримечательностям», но требует уточнения местоположения перед включением в маршрут.
