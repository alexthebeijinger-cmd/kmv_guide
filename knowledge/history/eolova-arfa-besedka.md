# Беседка «Эолова арфа»

**Категория:** памятник архитектуры федерального значения, пункт «максимум достопримечательностей» (запрос Alex, 30.07.2026). Ранее объект упоминался только как географический ориентир (`parks/emanuelevsky-park.md`, мониторинг кофеен §33) — теперь заведён собственной карточкой.
**Статус:** черновик, источник — Яндекс.Карты (мониторинг Alex через Claude, 30.07.2026).

## Кратко

Яндекс.Карты: **5,0 (6233 оценки)**. Построена в 1831 году по проекту братьев-архитекторов Бернардацци, названа в честь бога ветра Эола. Круглая ротонда с восемью колоннами в стиле античного храма, расположена в Емануелевском парке (`parks/emanuelevsky-park.md`, уже в базе). Изначально звук создавали настоящие арфы, соединённые с флюгером на куполе — сегодня заменены современной акустической системой, звук больше не зависит от ветра.

## Для контента гида

- Прямая связка с уже задокументированным Емануелевским парком — одна из главных точек внутри него.
- **Осторожно с одноимённым кафе:** рядом на бул. Гагарина, 2А есть кафе «Эолова Арфа» (Яндекс 5,0/2494) — отдельный коммерческий объект, не путать с исторической беседкой. Ранее (§33) поиск этого кафе не дал результата — теперь найдено, стоит добавить отдельной карточкой в категорию кофеен/ресторанов при следующем заходе.
