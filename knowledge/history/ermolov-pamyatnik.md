# Памятник А.П. Ермолову

**Категория:** памятник, пункт «максимум достопримечательностей» (запрос Alex, 30.07.2026). Тот же исторический деятель, что уже фигурирует в базе через «Ермоловские ванны» (`history/ermolovskie-vanny.md`) и «Грот Дианы» (`history/grot-diany.md`, построен по его приказу).
**Статус:** черновик, источник — Яндекс.Карты (мониторинг Alex через Claude, 30.07.2026).

## Кратко

Яндекс.Карты: **4,8 (46 оценок)**. Классический памятник на высоком постаменте, реалистично выполнен. Расположен на улице Лермонтова, открыт в **2010 году** (по данным подборки).

## Для контента гида

- Третий объект базы, связанный с личностью генерала Ермолова — можно собрать в единый тематический мини-маршрут («Ермолов в Пятигорске»: памятник, Ермоловские ванны, Грот Дианы).
- **Обнаружен целый кластер памятников поблизости** (раздел «Похожие места рядом» на карточке): Вечный огонь (4,7), безымянный «Памятник», В.И. Ленин (4,6 — отдельная карточка `history/lenin-pamyatnik-vechny-ogon.md` уже создана), «Матери-Казачке» (4,3), «Помним и скорбим» (3,9), «Чёрный тюльпан» (4,2), «Ю.А. Гагарин», «Мы победили!», «Л.Н. Толстой» (3,8) — судя по всему, единый мемориальный комплекс/сквер на ул. Лермонтова. **Не охвачено данным заходом — вынесено в открытые вопросы для следующего цикла поиска.**
