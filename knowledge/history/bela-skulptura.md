# Скульптура «Бэла»

**Категория:** жанровая скульптура, часть маршрута литературных скульптур по мотивам «Героя нашего времени» Лермонтова, пункт «максимум достопримечательностей» (запрос Alex, 30.07.2026).
**Статус:** черновик, источник — Яндекс.Карты (мониторинг Alex через Claude, 30.07.2026).

## Кратко

Яндекс.Карты: **4,9 (112 оценок)**. Скульптура посвящена Бэле — героине одноимённой повести из романа М.Ю. Лермонтова «Герой нашего времени». Расположена в Емануелевском парке (`parks/emanuelevsky-park.md`, уже в базе), в 274 м от «Пироговских ванн».

## Для контента гида

- Часть литературного маршрута по Емануелевскому парку вместе с Максимом Максимычем (`history/maksim-maksimych-skulptura.md`), Печориным (`history/pechorin-skulptura.md`) и Княжной Мери (`history/knyazhna-meri-skulptura.md`) — все созданы этим же заходом.
