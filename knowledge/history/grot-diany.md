# Грот Дианы

**Категория:** искусственный грот, исторический памятник, пункт «максимум достопримечательностей» (запрос Alex, 30.07.2026). Не путать с уже задокументированным «Гротом Лермонтова» (`history/grot-lermontova.md`) — это два разных грота в разных парках.
**Статус:** черновик, источник — Яндекс.Карты (мониторинг Alex через Claude, 30.07.2026).

## Кратко

Яндекс.Карты: **4,9 (196 оценок)**, круглосуточно. Искусственно созданный грот у подножия склона Горячей горы, в парке «Цветник» (`parks/park-tsvetnik.md`, уже в базе). Построен в **1830 году** по приказу генерала А.П. Ермолова — того же деятеля, что дал имя уже задокументированным «Ермоловским ваннам» (`history/ermolovskie-vanny.md`). Входит в подборку «Гроты Пятигорска: природные и рукотворные достопримечательности» (4 места).

## Для контента гида

- Ещё одна точка внутри уже задокументированного парка «Цветник» — расширяет маршрут по парку наряду с солнечными часами, скульптурой «Отдыхающая», «Кисой Воробьяниновым».
- Связка с личностью Ермолова — тот же исторический персонаж стоит за несколькими объектами базы (Ермоловские ванны, Грот Дианы).
