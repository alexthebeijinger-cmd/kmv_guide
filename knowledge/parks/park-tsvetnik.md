# Парк «Цветник»

**Категория:** городской парк — одна из главных достопримечательностей Пятигорска, у подножия горы Машук.
**Статус:** черновик, источник — Яндекс.Карты (мониторинг Alex через Claude, 30.07.2026).

## Кратко

Яндекс.Карты: **5,0 (64 068 оценок)** — **самая большая выборка отзывов среди всех объектов базы на сегодняшний день**, круглосуточно, бесплатный вход. Площадь около 1,5 га, известен клумбами, меняющимися по сезону.

На территории: скульптура «Киса Воробьянинов» (герой «12 стульев» — по книге, «концессионеры» искали стул именно в Пятигорске), солнечные часы, Лермонтовский источник №2, скульптура «Отдыхающая», фонтан «Счастливый улов», скульптура «Пятигорская Бронза — Золотая антилопа» (пересечение с уже найденным брендом-сувенирным магазином `shopping/pyatigorskaya-bronza.md` — возможно, тот же производитель ставит парковые скульптуры), несколько фонтанов, туалет, скамейки.

## Для контента гида

- Обязательная точка почти любого маршрута по центру Пятигорска — по объёму отзывов это самый посещаемый и узнаваемый объект во всей базе.
- Хорошо для сценария «отдых с детьми» (94% положительных отзывов по этому аспекту) и «прогулки» (99%).
- **Слабое место — парковка** (25% негативных отзывов) и **доступность для маломобильных** (14% негативных) — стоит предупреждать заранее, если это релевантно.
