# Парк Кирова

**Категория:** городской парк + парк аттракционов (двойная категория на Яндекс.Картах) — хороший кандидат также для будущей категории «Детский досуг» (п.16 чек-листа).
**Статус:** черновик, источник — Яндекс.Карты (мониторинг Alex через Claude, 30.07.2026).

## Кратко

Яндекс.Карты: **4,7 (7374 оценки)**. Входит в подборку «Где можно прокатиться на аттракционах в Пятигорске».

## Для контента гида

- Двойной профиль (парк + аттракционы) делает его удобным для двух разных сценариев: спокойная прогулка и активный отдых с детьми.
