# Железнодорожный вокзал Пятигорск

**Категория:** транспортный узел, пункт 22 чек-листа («Транспортные узлы»).
**Статус:** черновик, источник — Яндекс.Карты (мониторинг Alex через Claude, 30.07.2026).

## Кратко

Яндекс.Карты: **7065 отзывов** (без сводного числового рейтинга в выдаче), круглосуточно. Сайт rzd.ru. Отзывы: персонал 83% положительных, расположение 79% положительных; слабые места — состояние платформ (43% положительных, то есть много нареканий) и ремонт здания (18% положительных, много негатива), доступность для маломобильных — сильно отрицательная (10% положительных).

## Для контента гида

- Уже связан с уже собранным транспортом города (`transport/avtobusy-marshrutki.md`) и с электричками — единая точка входа в город для гостей по железной дороге.
- Стоит предупреждать про доступность для маломобильных гостей — слабое место по отзывам.
