## Услуги (расширенный скоуп, зафиксировано с Alex — июль 2026)

**Решение:** категории «Услуги»/«Медицина» не было в исходном плане (`kmw-guide-plan.md`), но с июля 2026 скоуп явно расширен — собираем вообще все места и учреждения, которые могут быть полезны туристу или отдыхающему, независимо от длительности визита (санаторный на 2–3 недели, турист выходного дня, транзитник на день). Логика: у любого гостя может внезапно возникнуть практическая потребность (заболел зуб, нужна аптека, нужен банкомат) — бот должен уметь ответить на такой запрос, а не только рекомендовать достопримечательности и рестораны. Верхнего порога по количеству материалов нет — пополняется по мере обнаружения.

**Собрано:**

1. Диагностический стоматологический центр «ООО Стоматолог» (ул. Теплосерная, 102, ежедневно 09:00–19:00, перерыв 13:30–14:00) — полный спектр стоматологии для взрослых и детей, 4 филиала по городу, рейтинг 4,8. Подробности: `knowledge/services/stomatologiya-teplosernaya.md`.

**Возможные подкатегории для дальнейшего сбора (черновой список, не зафиксирован явно, для ориентира):**

- медицина: аптеки (круглосуточные — отдельно отметить), поликлиники/травмпункт, скорая помощь — единый номер, стоматологии (кроме уже собранной)
- деньги: банкоматы/отделения банков, обмен валюты (важно для иностранных туристов, в т.ч. китайских — раздел 1 плана)
- связь: салоны сотовой связи (покупка SIM-карт для иностранцев)
- бытовое: прачечные/химчистки, парикмахерские/барбершопы
- прочее — любые места, которые встретятся по факту сбора на месте, не ограничиваться списком выше

Список подкатегорий — рабочий ориентир, а не жёсткое техзадание; главный принцип по решению Alex — собирать всё полезное, что попадается, без предварительной фильтрации по категориям.
