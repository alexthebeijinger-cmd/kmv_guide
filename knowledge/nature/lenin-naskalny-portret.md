# Наскальный портрет В.И. Ленина — гора Машук

**Категория:** достопримечательность (наскальный барельеф) на склоне горы Машук, часть маршрута по горным тропам.
**Статус:** черновик, источник — Яндекс.Карты (мониторинг Alex через Claude, 30.07.2026). 2ГИС для природных/монументальных объектов не даёт надёжного совпадения (не бизнес-справочник) — см. методологическую заметку в OPEN-QUESTIONS.md §36.

## Кратко

Портрет В.И. Ленина, нарисованный на скале на горе Машук. Яндекс.Карты: **4,8 (442 оценки)**. Входит в подборку Яндекса «Достопримечательности Пятигорска: маршруты по горным тропам» вместе с канатной дорогой, местом дуэли Лермонтова, Воротами Солнца, Ленинскими скалами и надписью «Пятигорск».
