# Скульптура «Орёл» на вершине Машука

**Категория:** жанровая скульптура на смотровой площадке, пункт «максимум достопримечательностей» (запрос Alex, 30.07.2026).
**Статус:** черновик, источник — Яндекс.Карты (мониторинг Alex через Claude, 30.07.2026).

## Кратко

Яндекс.Карты: **5,0 (133 оценки)**. Установлена в **2016 году** на вершине горы Машук — популярное место для фотографирования с прекрасным видом на город.

**Закрывает открытый вопрос из карточки `nature/mashuk-vershina.md`** (раздел «17-бис», вопрос №13): там упоминается «деревянная скульптура орла на каменном пьедестале» на вершине Машука с пометкой «автор и год не выяснены» — судя по названию и расположению, это тот же объект, **год установки — 2016** теперь известен (автор по-прежнему не найден). Не путать с бронзовым памятником «Орёл, терзающий змею» на Горячей горе (`nature/orel-terzayuschy-zmeyu.md`, уже в базе) — это два разных орла в разных частях города, как уже отмечено в мониторинге вершины Машука.
